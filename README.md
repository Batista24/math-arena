# Math Arena

Juegos de matemática para secundaria (1ro a 6to): Trivia, Carrera de operaciones, Bingo, Escape room, Ruleta para el aula e Impostor matemático.

*Con amor, para la maestra que hace aprender jugando.*

- Funciona sin servidor ni base de datos: los usuarios y puntajes se guardan en el dispositivo.
- Se puede instalar en el celular desde el navegador ("Agregar a pantalla de inicio").
